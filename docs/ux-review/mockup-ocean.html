  • Popup: a navy header band (white logo tile, "Tracking on" pill) over a pale-blue body; flat white cards with thin borders, no heavy shadows. The timer ring is teal.
  • Friction/intention: pale blue → seafoam page with a gentle wave along the bottom; the countdown ring is sand-colored, which reads as "wait" without alarm.
  • Type: Segoe UI Variable (built into Windows, falls back to system UI), 12 / 14 / 15 / 18 / 24 / 38 px. Radius 12 px cards, 8 px controls. Spacing 8-pt grid (8, 16, 24).
  • Distraction is burnt orange (#b9461a) rather than red, so Study teal vs Distraction orange stays distinct for red-green colorblind users; icons + labels are kept anyway.
  • All text colors pass WCAG AA (4.5:1) on their backgrounds; category meaning always has an icon + label, and the Distraction bar segment is striped (as in the P11 charts).
